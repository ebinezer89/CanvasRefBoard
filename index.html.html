When saving to the cloud, CanvasRef overwrites the existing cloud board file in your Google Drive. Fetching downloads that cloud file and updates your active workspace.

Bidirectional Overwrite Rule: When you hit Save / Overwrite, the destination file (Local or Cloud) is updated to match your live canvas. When you hit Fetch, the file from storage replaces your current board.

Google Identity / OAuth Settings

To connect real Google Drive, enter your Google Cloud OAuth Client ID (or use the built-in Sandbox / Mock Cloud Drive for testing offline).

How to get your free Google Drive Client ID

1. Go to Google Cloud Console.

2. Create a Project, then enable the Google Drive API.

3. Under OAuth consent screen, select External and add your email as a test user.

4. Go to Credentials → Create Credentials → OAuth Client ID (Web application).

5. Add your current website URL or http://localhost to Authorized JavaScript origins.

6. Paste the generated Client ID above.

PureRef Navigation & Features

Navigation (PureRef style):

• Pan: Right-Click drag, Middle-Click drag, or Space + Left-Click drag anytime.

• Zoom: Scroll wheel centered on cursor, or two-finger pinch on tablet.

• Paste: Press Ctrl+V to paste clipboard screenshots.

Per-Object Drawing & Layering:

• True Z-Stacking: Strokes drawn on an image or note are embedded on that object's local canvas. Placing another card over it naturally covers the drawing!

• Draw Without Text Interruption: Notes never trigger text editing while in Draw mode. Switch to Select Mode (V) to type notes.

• Continuous Marker: Silky flat highlighter with zero overlapping disc artifacts.

• Universal Lasso: Circle strokes, images, and notes together to move or delete as one cluster.

Dual Storage & Cloud Sync:

• Press S to open Settings.

• Pick a dedicated directory on your PC or tablet for single-click local folder overwrite.

• Connect Google Drive or enable Mock Sandbox Cloud for instant bidirectional cloud sync.
